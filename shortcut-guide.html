🏆 Steps Leaderboard

Log your daily steps automatically from your iPhone. ~5 minutes to set up, then it runs itself.

1 Get your token

Whoever invited you will give you a personal token — a short secret string like M-JIW2sSgf28E3N1KL68t0l1VxVDXbve. Keep it handy; you'll paste it in two places below. Don't share it — it's how the app knows the steps are yours.

2 Add the app to your Home Screen

Open this link in Safari:

«paste your app link here»

Tap the Share icon → Add to Home Screen. Open it from your Home Screen, paste your token once when asked, and you're in — you'll see the leaderboard, a submit form, and your history.

You can already submit steps by hand on the Submit tab. Step 3 below just makes it happen automatically every day so you never forget.

3 Add the Shortcut

Option A — one tap (easiest):

➕ Add to Shortcuts

On iPhone this opens the Shortcuts app and shows an Add Shortcut screen — tap Add Shortcut. (Apple requires that one tap; a website can't install it completely silently.) After it's added, open it once and paste your token into the Text action at the very top — that's the only thing you change.

— or build it yourself —

Option B — build it manually. Open the Shortcuts app → tap + → Add Action, and add these actions in order. Search each name in the action list.

  1. Text
    • Type your token here — just the token, nothing else. This is the one thing each person sets; everything below stays identical for everyone.
  2. Find Health Samples
    • Sample Type: Steps
    • Add Filter → Start Date · is · Today
  3. Calculate Statistics
    • Operation: Sum
    • Of: Health Samples (the result of the action above)
  4. Round Number
    • Round Statistics Result to the nearest 1 — steps must be a whole number.
  5. Format Date
    • Date: Current Date
    • Date Format: Custom → yyyy-MM-dd
  6. Get Contents of URL
    • URL (tap the URL field and paste this):
    https://step-tracker-101.onrender.com/steps
    • Tap Show More, set Method to POST
    • Under Headers, add one — Key: Authorization, Value: type Bearer (with a trailing space) then insert the Text variable from action 1 (your token)
    • Set Request Body to JSON and add these three fields:
    KeyTypeValue
    dateTextthe Formatted Date variable
    stepsNumberthe Rounded Number variable
    sourceTextshortcut
    To insert a variable (Formatted Date / Rounded Number), tap the value field and pick it from the suggestion bar above the keyboard.

Name it something like “Log my steps” and tap the ▶︎ to test it. The first run asks for Health permission — allow it. If it worked, open the app and you'll see your steps on the leaderboard. 🎉

4 Make it run automatically

In the Shortcuts app, go to the Automation tab → + → Time of Day:

  • Pick a time — 11:00 PM is a good end-of-day snapshot
  • Frequency: Daily
  • Choose Run Immediately and turn off “Ask Before Running”
  • Select your “Log my steps” shortcut
Running it more than once a day is totally safe — the app keeps one entry per day and just updates today's number. So you can set the automation to every hour if you want a live-ish count, or leave it at 11 PM for a clean daily total.

? If something's off

  • “Invalid token” — check the header is exactly Bearer + your token (one space, no quotes).
  • Steps look wrong / rejected — make sure you added the Round Number action; the count must be a whole number between 0 and 200,000.
  • Nothing shows on the leaderboard — give it a few seconds and pull to refresh; the server may take ~30s to wake up the first time each day.
  • Wrong day — the date uses yyyy-MM-dd and the group's timezone; that's expected, everyone's on the same clock.
